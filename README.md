# 🌿 건강하게 사는 법 — 생활 습관 자가진단

최근 일주일의 **수면 · 활동량 · 식사 · 화면 시간**을 10문항으로 점검하고,
100점 환산 점수와 영역별 등급, 이번 주에 바꿀 행동 하나를 돌려주는 Streamlit 웹 페이지다.

로그인·저장·수집이 없고, 결과는 주소 링크 하나로 누구에게나 공유할 수 있는 **공개형 페이지**다.

---

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

기본 주소는 `http://localhost:8501` 이다.

## 배포 (누구나 열 수 있는 공개 링크 만들기)

Streamlit Community Cloud에 올리면 별도 서버 없이 공개 URL이 생긴다.

1. 이 저장소를 GitHub에 올린다 (이미 올라가 있다).
2. [share.streamlit.io](https://share.streamlit.io) 에 GitHub 계정으로 로그인한다.
3. **New app** → 저장소 / 브랜치 / `app.py` 를 고른다.
4. **Advanced settings** 에서 Python 3.11 이상을 고른다. 의존성은 `requirements.txt` 를 자동으로 읽는다.
5. Deploy 후 앱 설정의 **Sharing** 을 `Public — anyone can view this app` 으로 둔다.

배포된 주소(`https://<앱이름>.streamlit.app`)를 그대로 공유하면 누구나 진단할 수 있다.

## 결과 공유가 되는 방식

응답 10문항을 `0`(2점) / `1`(1점) / `2`(0점) 숫자 10자리로 이어 붙여 주소의 `?a=` 파라미터에 담는다.

```
https://<앱주소>/?a=0120121021
```

이 링크를 열면 같은 결과 화면이 그대로 열린다. 서버에 아무것도 저장하지 않으며,
링크에 담기는 것은 문항 응답 10자리뿐이다. 형식이 맞지 않는 코드는 무시하고 첫 화면을 연다.

## 채점 방식

- 모든 문항의 기준은 **최근 일주일**이다.
- 각 문항은 3점 척도이며 보기 순서대로 **2점 / 1점 / 0점**이다.
- 10문항 **20점 만점**을 100점으로 환산한다 (`총점 ÷ 20 × 100`).
- 영역별로도 백분율을 내어 등급을 매긴다.

| 백분율 | 등급 |
| --- | --- |
| 75 이상 | 🟢 양호 |
| 45 ~ 74 | 🟡 주의 |
| 45 미만 | 🔴 점검 필요 |

## 문항 구성

| 영역 | 문항 | 보기 (2점 / 1점 / 0점) |
| --- | --- | --- |
| 🌙 수면 | 평일 밤 실제 수면 시간 | 8시간 이상 / 6~8시간 / 6시간 미만 |
| 🌙 수면 | 주말 기상 시각과 평일의 차이 | 1시간 이내 / 1~2시간 / 2시간 초과 |
| 🌙 수면 | 아침에 개운하게 일어난 날 수 | 5일 이상 / 2~4일 / 거의 없음 |
| 🏃 활동량 | 숨이 차거나 땀날 정도로 움직인 날 수 | 5일 이상 / 2~4일 / 1일 이하 |
| 🏃 활동량 | 한 번 앉았을 때 연속 착석 시간 | 1시간 이내 / 1~2시간 / 2시간 초과 |
| 🥗 식사 | 아침 식사를 한 날 수 | 5일 이상 / 2~4일 / 1일 이하 |
| 🥗 식사 | 단맛 음료 섭취 빈도 | 거의 없음 / 주 2~4회 / 거의 매일 |
| 🥗 식사 | 채소·과일 섭취 빈도 | 매일 / 가끔 / 거의 없음 |
| 📱 화면 시간 | 공부 외 목적의 하루 화면 사용 시간 | 2시간 이하 / 2~4시간 / 4시간 초과 |
| 📱 화면 시간 | 잠들기 직전 화면 사용 여부 | 거의 없음 / 가끔 / 거의 매일 |

## 화면 구성

1. **랜딩** — 진단 소개, 영역·채점 방식·등급 기준 안내, 생활 가이드
2. **진단** — 10문항 응답 (진행률 표시, 전부 응답해야 결과 버튼 활성화)
3. **결과** — 총점 게이지 · 영역 레이더 차트 · 영역별 카드 · 문항별 해설 ·
   이번 주 실천 카드 · 결과 공유(요약 텍스트 / 링크 / `.md` 리포트) · 영역별 생활 가이드

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `app.py` | Streamlit UI 전체 (랜딩 / 진단 / 결과 / 공유 / 가이드) |
| `content.py` | 문항·보기·해설·실천 행동·생활 가이드 텍스트 |
| `scoring.py` | 채점, 등급 산출, 공유 코드 인코딩·디코딩 |
| `.streamlit/config.toml` | 테마 설정 |
| `requirements.txt` | 의존성 (streamlit, plotly) |

문항이나 문구를 바꾸려면 `content.py` 만 고치면 된다. 문항을 추가·삭제해도
만점과 공유 코드 길이는 `scoring.py` 가 자동으로 따라간다.

## 안내

이 진단은 생활 습관을 스스로 돌아보기 위한 자가 점검 도구이며 의학적 진단이 아니다.
수면·기분·체중에 지속적인 변화가 있다면 의료 전문가와 상담하는 것을 권한다.
